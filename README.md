# IdeaBox

Mini SaaS per salvare e gestire idee.

## Funzionalità

- Aggiunta di nuove idee
- Segna idea come completata
- Eliminazione singola
- Eliminazione delle idee completate
- Conteggio totale / completate / da fare
- Salvataggio automatico nel browser
- Responsive mobile

## Avvio

Non serve installare nulla.

Apri `index.html` in un browser.

## Deploy su Replit

1. Crea un repository GitHub.
2. Carica i file:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Su Replit importa il repository GitHub.
4. Apri `index.html`.

## Stack

HTML
CSS
JavaScript

## Nota

I dati sono salvati tramite localStorage del browser.
Questo progetto è volutamente semplice ed è stato creato per testare il flusso:

ChatGPT → GitHub → Replit
